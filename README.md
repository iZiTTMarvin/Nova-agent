## 一句话介绍

想做个小工具？想让 AI 帮你改个 bug？想从零搭个项目？

别再一步步敲命令了。打开 Nova Agent，**像跟朋友聊天一样说一句话**——

> "帮我做一个待办事项 app"
> "修一下登录页那个 bug"
> "给这个项目加个深色模式"

它会自己想清楚要做什么、自己动手做、自己检查一遍、最后把结果交给你。

**你不是 prompt 工程师，也不是全栈开发者，你只是有个想法的人。** Nova Agent 帮你把想法变成能用的东西。

> 适合：新手、业余开发者、想偷懒的打工人。

## 它能帮你做什么

### 一次说完整件事，它按流程跑完

别人家的 AI 助手让你一步步来——`/plan` 看规划，`/run` 跑任务，`/test` 跑测试……学起来累不累？

**Nova Agent 不这样。** 新建会话时选 **XForge** 模式，直接说：`帮我做一个番茄钟 app`。主 Agent 会沿着六个阶段亲自把事做完：

**构思 → 计划 → 开发 → 验证 → 审查 → 收尾**

- 先跟你对齐想法，再写出一份计划**给你过目**，你点头了才开工
- 开发完自己跑验证，然后派一个**只读的子代理**独立审查——不是自己检查自己
- 聊天顶部有阶段条，六个阶段走到哪一目了然，也能手动跳过或回退
- 中途关掉应用？重开会话，**从停下的阶段接着来**
- 赶时间可以打开「全自动完成」，流程确认自动放行，但权限门禁照常生效

### 聊久了也不会失忆、不会爆金币

AI 助手最烦人的两个毛病：聊着聊着忘了前面说过什么、账单越烧越离谱。
Nova Agent 专门把这两件事做扎实了——长会话不丢上下文，成本也压得住。**跑几个小时的活儿，账单不会爆。**

### 聊错了可以反悔

AI 给的回答不满意？想换个方向试试？
**直接分叉。** 在某条消息那里开个新分支，让它重新来——之前的工作不丢，只是被你"存档"了，可以随时切回去。

### 它记得你的项目

今天聊过的项目背景、文件结构、你的偏好——**它会记着**。
下次开新会话，不用重新介绍一遍"我这个项目是做啥的"。

### 你说什么它都会干

读文件、改文件、跑命令、搜代码、搜网页、装依赖、查文档……常用的事 Nova Agent 都会干。

- 高危操作（删文件、跑危险命令）会有确认弹窗，**不会偷偷搞坏你的项目**
- 它改过的文件会列成清单，每个文件都能看差异、**逐个接受或拒绝**

## 三种模式怎么选

| 模式 | 适合干什么 |
|------|-----------|
| **默认模式** | 日常聊天式协作：改个 bug、问个问题、小步快跑 |
| **计划模式** | 先只读分析项目，产出一份计划文档给你确认，确认后再开工 |
| **XForge** | 从头做一件事：六阶段全流程推进，适合"帮我做个 app"这种完整需求 |

新建会话时在左上角 **+** 菜单里选模式；XForge 会话顶部有模式标签，点 × 随时退出。

## 3 分钟上手

需要装 [Node.js 18+](https://nodejs.org/)。准备好你的 API Key：MiniMax / GLM / DeepSeek 有内置预设一键填；Ollama 本地模型和任意 OpenAI 兼容服务（Kimi、通义等）也能接。

```bash
git clone <repository-url>
cd nova-agent
npm install
npm run dev
```

启动后：

1. 填 API Key（侧边栏底部 **设置 → LLM 配置**）
2. 选个模型
3. 选个项目文件夹

然后——**在对话框里直接说你想做什么**。

第一次不知道说啥？输入 `/onboard`，Nova Agent 会带你熟悉一遍。

想直接跑完整流程？新建会话选 **XForge** 模式，输入 `帮我做一个待办事项 app`。

## 现成能用的"小帮手"

Nova Agent 装好就有这些开箱即用的技能，输入 `/` 就能看到：

| 名称 | 干啥用 |
|------|--------|
| `/onboard` | 首次上手向导：了解工作区、配置规则与技能 |
| `/deep-research` | 深度调研：拆子问题并行检索，结论带来源引用 |
| `/code-review` | 代码审查：对 git 变更做只读审查，给出带文件行号的问题清单 |
| `/nova-frontend` | 创建或重构高质量前端界面，不像 AI 套模板 |
| `/skill-creator` | 想自己做技能？照着做 |
| `/skill-add` | 从 URL 或 zip 装个新技能 |
| `/new` | 空白技能模板，做自己技能的起点 |

想加新技能？三条路任选：把 `SKILL.md` 丢进 `~/.nova/skills/<name>/`（全局生效）、放进 `<你的项目>/.nova/skills/<name>/`（仅当前项目生效）、或用 `/skill-add` 从网上装。重启就生效。

## 钱怎么算

Nova Agent 本身**免费**（MIT 开源）。你只需要自己出 AI 调用的钱——也就是你 API Key 对应服务商的价格。

Nova Agent 在「长会话省钱」这件事上做了不少功夫：提示词缓存稳定命中不重复计费、自动在合适时机压缩长对话、分支探索不污染主线开销。**长跑几个小时的活，账单比一般 Agent 明显低。**

## 跑得动什么、跑不动什么

- **跑得动**：长任务（小时级）、多步骤、多文件改动的活儿
- **跑得动**：跑测试、装依赖、查文档、读代码、改代码
- **不擅长**：需要你实时看屏幕做判断的事
- **不擅长**：连上你的真机做部署

## 常见问题

**Q: 我不会写代码能用吗？**
A: 可以。你不用写代码，你只需要用**自然语言告诉它你想做什么**。

**Q: Windows 能装吗？**
A: 能。还可以打成一键安装包（`npm run dist` 出来就是个 `.exe`）。

**Q: 跟 Cursor / Claude Code 比呢？**
A: 那些主要在编辑器里用，前提是你得会写代码。Nova Agent 是**完整的桌面 app**，核心是 XForge 模式下说一句话就按六阶段跑完整流程：计划先给你过目，改动逐文件审阅，不用你记命令。

**Q: 「全自动完成」安全吗？**
A: 自动放行的只是"计划批准、进入下一阶段"这类流程确认。删文件、跑危险命令仍然会弹窗找你；而且构思、计划阶段对项目只有只读权限（计划文档除外），进入开发阶段才放开文件写入。

**Q: 数据安全吗？**
A: Nova Agent 是**本地桌面 app**，对话、文件、检查点都存在你电脑上，不上传第三方。AI 调用走你自己的 API Key，流量只在你和服务商之间。

**Q: API Key 必须用自己的？**
A: 对。Nova Agent 不收 Key、不中转请求、不抽成。

**Q: 出错了怎么办？**
A: 大部分小问题它自己就处理了：网络抖了自动重试、对话太长自动压缩、主模型挂了自动切备选模型接着干。
