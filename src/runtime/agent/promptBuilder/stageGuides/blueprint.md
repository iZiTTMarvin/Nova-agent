# 图

## 做什么
起草一页纸四段：你要的东西 / 做完你能做什么（可操作、可观察的条目，编号）/ 我决定不做的 / 技术选择（每项附一句理由）。
派 critic 子代理，只给它这一页纸；根据意见修订，把砍掉的移入「不做的」。
用 save_plan 保存修订后的一页纸；在对话里用一两句话告诉用户批评者砍了什么、补了什么。
保存时把验收能力逐条放入 capabilities 数组，正文放入 content；能力清单标题和编号由程序生成。

## 做到什么算完
修订后的一页纸已保存，批评者的砍与补已写进正文。

## 怎么交接
调用 stage_transition complete，等待用户确认。用户要改就修订同一份计划再提交。
