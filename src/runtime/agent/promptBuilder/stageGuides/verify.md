# 验证阶段

## 目标
亲自运行与改动范围对应的验证：typecheck、相关测试、构建（按项目实际配置），失败就修到全绿。验证证据（跑过的命令与真实结果）留在消息流中，供审查与交付引用。

## 工具边界
本阶段不再按阶段收窄工具；危险命令仍会被既有策略拦截。

## 完成标准
相关验证命令全部真实通过。禁止假绿：只断言非空、放宽断言、吞掉错误来让测试通过，都不算完成。

## 交接约定
全绿后，调用 stage_transition（action: complete）进入「审查」阶段。验证暴露实现问题时，调用 stage_transition（action: return）回退到「开发」阶段修复，需注明原因。
